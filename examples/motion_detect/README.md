# Motion Detect Example

A simple image example. It compares two built-in frames and reports whether the scene is moving.

## Quick start

Follow the [quick start](https://docs.espressif.com/projects/esp-dl/en/latest/getting_started/readme.html#quick-start) to flash the example.
